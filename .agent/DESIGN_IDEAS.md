# DESIGN_IDEAS.md — Design Ideas for Later (Backlog)

> **Purpose:** Parking lot for nice-to-have UX that is NOT in v1 but should be kept for post-launch.
> **Source:** Stitch explorations, moonsites.ai, tasteskill.dev, 21st.dev, v0.dev, UI/UX Pro Max

---

## 1. Generative Home Evolutions

- AI-generated daily challenge card on Home (based on last lesson, Gemini suggests)
- Confetti + streak flame animation (Lottie) when streak extended
- Parallax banner carousel for promotions (50% etc.) with auto-scroll
- Subject mastery radial charts per language

## 2. Code Editor Enhancements

- Inline AI hint gutter (lightbulb where Gemini suggests fix, tap to apply)
- Collaborative cursor (teacher view same code — future WebRTC)
- Vim mode toggle (for advanced)
- Output diff view for hidden tests (expected vs actual side-by-side)

## 3. Video & Learning

- Picture-in-Picture drag for Shorts while coding
- Whiteboard annotation: student can draw on paused whiteboard frame, save to Notes
- Speed 1.5x/2x with pitch correction, auto-generated transcript (Gemini + YouTube captions)

## 4. Gamification

- Leaderboard per classLevel + subject (Supabase materialized view)
- Badges: "First PR", "7-day streak", "100 MCQs"
- XP bar on Practise page

## 5. NeoBrutalish Variants

- Toggle per-screen: Neo for Home/Learn, Modern for Editor/Chat
- Custom font slider (Inter vs Space Grotesk for headings)

## 6. Monetization & Promo

- Referral: share 50% promo code, both get +7 days Pro
- Festival skins (Diwali theme) — temporary primary color override

## 7. Accessibility & Polish

- Dyslexia font toggle (OpenDyslexic)
- Haptics on correct MCQ, error buzz on fail
- Voice input for AI Chat (Speech-to-Text)
